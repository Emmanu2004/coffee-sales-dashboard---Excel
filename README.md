## Coffee Sales Dashboard

This project showcases an interactive Coffee Sales Dashboard developed in Microsoft Excel. The dashboard provides insights into sales performance, customer purchasing behavior, and product trends through dynamic visualizations and filters.

### Features
- Sales trend analysis over time
- Product-wise sales performance tracking
- Customer purchase analysis
- Country-wise sales comparison
- Interactive filtering using slicers
- Automated reporting through Pivot Tables and Pivot Charts

### Tools & Techniques
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
- Business Reporting

### Business Value
The dashboard helps stakeholders monitor key sales metrics, identify top-performing products, understand customer behavior, and make data-driven business decisions.
